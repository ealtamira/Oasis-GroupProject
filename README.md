# Oasis-GroupProject

Oasis is a web-based implementation of the classic strategy game Connect 5. Developed as a collaborative group project, this application moves beyond the traditional 1v1 local play by integrating an automated AI opponent to challenge players' strategic depth.
🚀 Key Features

    1v1 Local Multiplayer: Play against a friend on a shared interface with a responsive, grid-based game board.

    AI Opponent (Beta): Challenge a computer-controlled player designed to recognize patterns and block winning streaks.

    Dynamic Win Detection: Custom logic to identify 5-in-a-row across horizontal, vertical, and diagonal axes.

    Modern Web UI: A clean, "Oasis"-themed interface built for a seamless user experience.

🧠 The AI Challenge

The core of our technical exploration involved implementing an AI that goes beyond random moves. We focused on:

    Pattern Recognition: Teaching the AI to identify "open fours" and "split threes."

    Minimax Principles: Experimenting with decision-making trees to anticipate player moves.

    Heuristic Evaluation: Scoring the board state to prioritize center-control and defensive blocking.
